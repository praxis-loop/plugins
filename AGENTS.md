# Agent Rules

## Repository Purpose

This repository is the source of truth for curated, cross-platform AI agent plugins.
Approved runtime snapshots live under:

```text
plugins/<plugin-name>/
```

The repository publishes two catalogs over the same plugin snapshots:

- `.agents/plugins/marketplace.json` for Codex and ChatGPT.
- `.claude-plugin/marketplace.json` for Claude Code.

## Required Checks

After modifying plugins, sources, overlays, tooling, docs, templates, scripts, or marketplace files, run:

```bash
git status --short
npm test
node tools/pluginctl check
bash scripts/doctor.sh
```

On Windows without a working Bash/WSL runtime, run
`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/doctor.ps1` as the equivalent final check.

## Sync Responsibility

After a change, explicitly report whether the repository has uncommitted changes, unpushed commits,
remote commits to pull, or a clean synchronized state. Commit and push only when the user asks to
synchronize or publish.

## Third-party Plugin Supply Chain

- Declare external plugins in `sources/plugins.sources.yaml`.
- Lock exact commits, tree hashes, content hashes, platform support, and review flags in
  `.xan/plugins.lock.json`.
- Keep approved snapshots under `plugins/`; never hand-edit them.
- Use `overlays/<plugin-name>/overlay.yaml` for small adaptations or fork upstream for large changes.
- Treat new hooks, MCP servers, executable scripts, network commands, package installs, destructive
  commands, and secret-path mentions as review-required changes.
- Do not restore a separate registry file; the filesystem and generated platform marketplaces are
  the sources of truth.

## Cross-platform Rules

- A plugin declaring `codex` support must contain `.codex-plugin/plugin.json`.
- A plugin declaring `claude` support must contain `.claude-plugin/plugin.json`.
- The manifest names must match the plugin directory and each other.
- Keep platform-specific manifests and hooks in the plugin snapshot; do not flatten them into the
  repository root.
- Root marketplace files are generated by `pluginctl`; do not edit them by hand.

## Safety

- Never commit secrets, tokens, private keys, `.env` files, or machine-specific configuration.
- Ask before deleting data, publishing changes, sending messages, spending money, or changing
  production systems.
- Do not overwrite an existing real plugin directory during installation. Back it up or move it first.
